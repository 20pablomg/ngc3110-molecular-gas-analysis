# Private input data

The original IRAM 30 m observations, ALMA FITS images, SSC catalogues and third-party maps are **not distributed**. They are not owned solely by the repository author. Obtain permission and the appropriate datasets separately before attempting a rerun. Do not open a pull request containing observational data.

Expected locations and names are documented in [Reproducibility](../docs/REPRODUCIBILITY.md). The scientific analysis notebooks require these original inputs and derived intermediate data products; viewing the source code and selected retained figures does not.
