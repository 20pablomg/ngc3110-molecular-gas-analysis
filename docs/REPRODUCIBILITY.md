# Reproducibility and scientific caveats

**Status:** Source code, selected original notebook outputs and a refactored conversion utility are provided. No raw FITS data, spectra or derived `.dat` files are included. A full scientific rerun **was not possible**, and the provided figures are retained outputs from the original thesis—not evidence of execution of the adapted notebooks.

## Required private inputs

- `results/ResultadosCO/line_12co10_contsub_clean20_nat.regrid.immath.moment0.fits`
- `results/ResultadosCO/ngc3110_co21_081011_LINE.fits.image.integrated.fits`
- `results/ResultadosSCCs/SSCs_SurfaceDensity.fits`
- `results/ResultadosSCCs/NGC3110-NIR-Zara-wreg.fits`
- `spectra/W_<region><line>_spectrum.dat` from the GILDAS spectral stage (region prefixes N, C, S)
- `results/ResultadosCLASS/W_<line>_fit_results.dat` and `W_<line>_moment_results.dat`
- `results/ResultadosHNC/upper_limit_HNC_2_results.dat`

Place permitted private inputs in these relative locations under the repository root. Python notebooks locate the root from the working directory (root or `notebooks/`) and do not depend on a Windows username or absolute drive path. CLASS scripts remain **dataset-specific** and assume an explicit working-directory layout and a configured GILDAS installation.

## CLASS export

`gildas/gauss.class` is a **single-pointing example**, currently configured for South HNC. Its earlier `write_results.py` dependency has been replaced by direct `SIC OUTPUT` of a Gaussian fit table (`I_fit`, `err_I`) and a manual velocity integral (`I_manual`, `SigmaI`). It intentionally does not manufacture a separate independent `I_moment` measurement. The converter handles both formats (with or without `I_moment`). This CLASS adaptation has **not** been executed in GILDAS. CLASS inputs, velocity windows, paths and output filenames must be customized for each spectrum. The original CLASS reduction was not a general-purpose batch pipeline.

## Scientific checks still required

- Several original molecular-ratio calculations pair independently ordered tables by row index, rather than joining by `fuente`; verify these correspondences against original outputs before reporting reproduced numbers.
- Original code had the HCN/HCO+ quotient reversed. The adapted code adjusts this but must be compared with thesis Table 9.
- The original SSC notebook uses `KPC_PER_ARCSEC = 0.325`, while the thesis adopts 0.352 kpc/arcsec. This **scientific discrepancy is not resolved** by changing paths.
- Compare observed/rest frequencies and beam corrections before physically reinterpreting the ALMA conversions.
- The retained notebook outputs are selected historical figures and must not be represented as freshly regenerated by the packaged notebooks.

## Public use

1. Install Python requirements from the repository root.
2. Review the notebooks and their retained representative figures in GitHub or Jupyter.
3. If authorized datasets are available, place them in the paths above and rerun notebooks from the project root.
4. Validate all numerics against the published thesis tables. Intermediate tables can be exported to `results/`, which is ignored by Git.
