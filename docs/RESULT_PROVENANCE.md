# Archived output provenance and scope

This repository embeds historical outputs from the five Jupyter notebooks delivered by the author. They are not generated from new telescope observations or recalculated in this package.

| Notebook | Archived content | Original file |
|---|---|---|
| 01 | 8 ALMA-map figures, simulation/flux tables and comparisons | `FLUJOSyMAPAS.ipynb` |
| 02 | 15 spectra: five molecular transitions in three regions each | `EspectrosTFG.ipynb` |
| 03 | Southern HNC non-detection console result | `CotaSuperiorHNC.ipynb` |
| 04 | Seven archived ratio result tables, shown with saved precision | `CalculosTFG.ipynb` |
| 05 | 3 map/image outputs and a saved SSC density table | `MapasSCC.ipynb` |

Tabular outputs in notebooks 03–05 were originally emitted using text streams and may be presented as preformatted tables; precision has not been altered. The source expressions have been adjusted for cleaner inline display on future reruns, but a full rerun needs private data.

**Publication warning:** Creating a derived plot does not automatically confer rights to redistribute it. Verify any telescope archive embargo, collaboration policy, and supervisor approval before publishing the repository or distributing derived visualizations.

No missing source files or measurements have been recreated. The original notebook 03 contained a result for the southern HNC pointing only. The thesis has additional summarized results which are not substituted into missing notebook outputs.
